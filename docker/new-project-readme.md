# New project

This is an empty project. Add your files by opening
`copy-your-files-here/{{PROJECT_NAME}}/` in your file manager (Finder /
Explorer) — inside the repo you cloned, that's this project's actual folder
on your machine. You can also drop files in directly from inside the IDE,
but for a large number of files the file manager is faster.

## Connect a model

Open the **Geology Agent** panel — it's on the right sidebar.

## Want to see an example first?

Go to [localhost:3000](http://localhost:3000) and click the `defaults`
project. (If you mapped the container to a different host port, use that
port instead of 3000.)
