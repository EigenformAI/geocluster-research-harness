# Geocluster Research Harness — your projects

Each subfolder in `copy-your-files-here/` is a separate project. Create a new
folder (or copy one in) for each project you want the agent to work on.

## Opening a project

When you open the IDE in your browser, you'll land on a page listing every
project folder found here — click one to open it, or use the form on that
same page to create a new one. That page always reflects what's currently in
this folder, so a project folder you copy in manually shows up the next time
you load the page too.

You can also jump straight to a project with a direct link:

```text
http://localhost:3000/?folder=/workspace/<project-name>
```

## `defaults/`

A small **synthetic** geology project is included in [`defaults/`](defaults/)
so you can try the agent right away. See `defaults/README.md` for what's in
it and a few prompts to try. Delete it whenever you don't need it anymore.

## First step: connect a model

Once you're inside a project, open the **Geology Agent** panel (right
