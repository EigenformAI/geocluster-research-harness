- `au_icsm_GDA94_GDA2020_conformal.tif`

## Immutable data sources

The PROJ-data source commit is
`cdab44864a36a9f3c3e90a36637c5d8a86e624c6`. The original ICSM source and licence
were inspected at commit `d2b26335dbc466c70334446c07463a6e95c5e115`.

The build downloads these exact URLs:

- <https://raw.githubusercontent.com/OSGeo/PROJ-data/cdab44864a36a9f3c3e90a36637c5d8a86e624c6/au_icsm/au_icsm_GDA94_GDA2020_conformal.tif>
- <https://raw.githubusercontent.com/OSGeo/PROJ-data/cdab44864a36a9f3c3e90a36637c5d8a86e624c6/au_icsm/au_icsm_GDA94_GDA2020_conformal_and_distortion.tif>

`grids.lock.json` records the SHA-256, byte size, licence, attribution, and datum
operation for each file. The pins match the official
[PROJ-data catalogue](https://github.com/OSGeo/PROJ-data/blob/cdab44864a36a9f3c3e90a36637c5d8a86e624c6/files.geojson).
Both immutable downloads were independently hashed on 2026-10-07 and matched that
catalogue. The two files total 31,833,886 bytes. The repository contains the pins,
not the grid binaries.

## Datum operations and grid selection

Both grids supply horizontal latitude and longitude offsets from GDA94
(`EPSG:4283`) to GDA2020 (`EPSG:7844`) within their grid coverage:

- Conformal: `EPSG:8446`, GDA94 to GDA2020 (3). This represents the conformal
  datum change without local distortion modelling.
- Conformal and distortion: `EPSG:8447`, GDA94 to GDA2020 (2). This adds the
  regional distortion component. The correct choice depends on the source
  survey's reference-frame history, not just its CRS label.

The [ICSM grid descriptions](https://github.com/icsm-au/transformation_grids/blob/d2b26335dbc466c70334446c07463a6e95c5e115/README.md#gda94--gda2020)
describe the two components and direct grid selection to Table 3.4 of the GDA2020
Technical Manual. The [PROJ-data ICSM inventory](https://github.com/OSGeo/PROJ-data/blob/cdab44864a36a9f3c3e90a36637c5d8a86e624c6/au_icsm/au_icsm_README.txt)
records the NTv2-to-GeoTIFF conversion and available grids.

This initial set covers GDA94 and GDA2020 horizontal workflows for mainland
Australia and Tasmania within the grids' actual extents. The separate Christmas
Island and Cocos (Keeling) Islands grids serve different geographic coverage.
AGD66 and AGD84 grids serve older source datums. AUSGeoid grids serve vertical
height transformations. Those resources are outside this initial grid set.

## Source-to-WGS84 limits

There is no additional dedicated GDA2020-to-WGS84 grid in this set. The cited
[PROJ operation catalogue](https://github.com/OSGeo/PROJ/blob/392b02d9811b8d513ffd8a8be78181e512e9afa5/data/sql/helmert_transformation.sql#L2220-L2223)
defines `EPSG:8450`, GDA2020 to WGS 84 (2), as a zero-translation approximation
to the WGS84 ensemble. Its nominal 3 m value is operation metadata, not evidence
of the accuracy of a dataset or of this runtime. `EPSG:8448`, GDA2020 to WGS 84
(G1762) (1), is a time-dependent rotation, not a downloadable grid.

The [GDA94 to WGS84 grid operation](https://github.com/OSGeo/PROJ/blob/392b02d9811b8d513ffd8a8be78181e512e9afa5/data/sql/grid_transformation.sql#L1124-L1127)
`EPSG:9689` reuses the conformal-and-distortion grid and is equivalent to
`EPSG:8447` followed by the null `EPSG:8450` operation. It does not supply a new
GDA2020-to-WGS84 correction. NSW Spatial Services' official
[WGS84 and Web Mercator explanation](https://www.nsw.gov.au/environment-land-and-water/surveying/geodesy-and-geocentric-datum-of-australia/gda2020)
describes the different alignments that a WGS84 label can conceal.

Grid presence establishes that these pinned grid bytes are available locally.
It does not establish the source datum, WGS84 realisation, coordinate epoch,
selected operation, area of applicability, axis order, or positional accuracy.
It does not transform heights or resolve unknown source CRS metadata. A valid
source-to-WGS84 pipeline still requires the native operation selection and its
recorded evidence.

## Build installation

`Dockerfile.gis-overlay` runs `node lib/gis-grids/build.mjs` as root. The script
uses Node's built-in HTTPS fetch and SHA-256 support. It rejects missing pins,
mutable URLs, redirects, failed or interrupted downloads, incorrect byte sizes,
and checksum mismatches. All fetched grids are verified before any installed
grid is replaced. A failed build cannot produce a successful overlay layer.

The installed grids, `gis-grids.lock.json`, and `gis-grids-LICENSE.txt` are
root-owned with mode `0444` in `/usr/share/proj`. The directory has mode `0555`.
The installer checks final file ownership, modes, sizes, and hashes. These files
are readable by the confined GIS worker through its existing read-only
`/usr/share/proj` allowance. Its fixed PROJ search path and `PROJ_NETWORK=OFF`
use local data without runtime downloads.

The standalone checksum tests use small synthetic fixtures in temporary directories.
They do not modify installed PROJ data. The final overlay build and confined
native operation qualification are separate verification steps.
