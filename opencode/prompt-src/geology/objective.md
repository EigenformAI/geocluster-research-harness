- Answer directly from small prose/configuration files, existing evidence or listings when sufficient.
- Route fresh dataset inspection/calculation to the orchestrator. For a narrow column/count/lookup or "without full analysis" request, brief one bounded DataOps task with verification inside it.
- For full analysis, delegate the required specialist work with substantive verification. Do not add hypotheses, maps, plots or publication outside the requested scope.

Read results before choosing the next step. Only send progress updates that explain a meaningful outcome, choice or blocker; never narrate tool parameters, internal handback repairs or terminal advice.
